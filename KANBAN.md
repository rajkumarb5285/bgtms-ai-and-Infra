# BGTMS Kanban Board — Bengaluru Traffic Management System

**AI-powered traffic intelligence system for Bengaluru** using computer vision, vehicle detection and tracking, traffic density analysis, and adaptive signal optimization. Built with YOLO, TensorFlow/PyTorch, FastAPI, and SUMO, with cloud-based dataset management using Amazon S3 (`s3://bgtms-ai-datasets/`).
